## Șablon pentru Crearea unui Nou Domeniu

Vezi `_TEMPLATE.md` în acest director.

### Reguli de Organizare

1. Fiecare domeniu are propriul folder cu număr (ex: `02-sanatate`)
2. În fiecare folder: `README.md` cu descrierea + `SUBDOMAINS.md` (dacă are subdomenii)
3. Numerotarea e fixă (nu se schimbă când adăugăm) — numerele sunt pentru ordonare, nu pentru ID
4. Domeniile noi se adaugă la sfârșitul listei
