# Atribuirea Sursei — Cum Credităm Instituțiile

> Regula de aur: **Fiecare dată afișată poartă numele instituției care a publicat-o.**

## Formatul Standard de Atribuire

```
Sursa: [Nume Instituție] — [Numele setului]
Link: [URL-ul original]
Licența: [OGL-ROU-1.0 | CC-BY-4.0]
Publicat: [Data]
```

### Exemplu

```
Sursa: Ministerul Sănătății — Paturi clinice în spitale 2024
Link: https://data.gov.ro/dataset/...
Licența: OGL-ROU-1.0
Publicat: 2024-06-15
```

## Unde Apare Atribuirea

| Locație | Format |
|---|---|
| Pagina set de date | La sfârșitul paginii, sub date |
| Pagina instituție | Subtitlu: „Date publicate de..." |
| Export CSV/JSON | În antetul fișierului: `# Sursa: ...` |
| API response | Câmp `sursa` în JSON |
| Hartă | Popup marker: „Date de la..." |
| Footer site | „Date preluate de la data.gov.ro, ONRC, BNR și alte instituții publice." |
